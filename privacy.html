Privacy Policy for PulseFinder

Effective Date: September 2026

1. Overview

PulseFinder ("we", "our", or "the Application") is an offline-first desktop community multiplayer server discovery directory developed by Bhavesh@Developers. We respect user privacy and operate under a strict client-side model.

2. Data Collection and Usage

PulseFinder does not collect, track, transmit, or harvest any personally identifiable information (PII). All user profile data, preference selections, and identity backups (.pulsekey files) are generated and stored strictly on your local device using standard browser/client storage APIs.

3. Subscriptions & Payment Processing

All in-app purchases and subscription transactions (Plus and Ultra plans) are processed directly by the official Microsoft Store Commerce Platform. PulseFinder does not collect, process, or retain any payment credentials, credit card numbers, or billing addresses. Payment transactions are governed entirely by Microsoft's Privacy Statement.

4. Third-Party Game Server Connections

PulseFinder serves as an indexing directory for public community-hosted multiplayer servers. Connecting to any third-party game server establishes a direct network connection between your device and that server host, governed by standard multiplayer network protocols. PulseFinder does not operate or control third-party game servers.

5. Contact Information

If you have any questions or concerns regarding this Privacy Policy, please contact the developer via the official Microsoft Store listing support link.
